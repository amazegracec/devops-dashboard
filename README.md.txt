# DevOps Dashboard

## Project Overview

This project is a simple web application created as part of the Level 5 DevOps module.

The application demonstrates DevOps principles including:

- Version Control using Git and GitHub
- Continuous Integration and Continuous Deployment (CI/CD)
- Infrastructure as Code (IaC)
- Cloud Deployment

## Application Features
 
- Application Status Display
- Environment Information
- User Feedback Form

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### DevOps Tools

- Git
- GitHub
- GitHub Actions

### Infrastructure

- Terraform
- AWS

## CI/CD Pipeline

The CI/CD pipeline automatically runs whenever changes are pushed to the main branch.

 
Pipeline stages:

1. Checkout source code
2. Validate application files
3. Run basic tests
4. Deploy application
 
## Architecture

Developer

↓
